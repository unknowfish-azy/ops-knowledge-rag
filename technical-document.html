1. 项目概述

智维Agent 面向中小企业运维场景，将大模型能力约束在"证据驱动、风险可控、全程留痕"的闭环内，解决通用问答机器人不可信、不可控、难落地的问题。系统覆盖知识获取 → 知识检索 → 证据验证 → AI 分析 → Agent 规划 → 风险控制 → 安全执行 → 结果验证 → 审计留痕的完整链路。

AI AgentRAG 证据验证SSE 流式思考过程可视化多模态风险策略引擎审计留痕

2. 系统架构

层技术栈职责
前端Vue 3 + Vite + Element Plus + Pinia + ECharts + Three.js（共享逻辑层 TypeScript）运维控制台、AI 对话面板（语音/图像证据/流式思考可视化）、3D 与图表可视化

AI 服务FastAPI（:8001）LLM 网关（可切换 Provider）、对话与 SSE 流式接口、RAG 编排
Agent 框架Pythonplanner（规划）/ executor（执行）/ inspector（核查）/ memory（记忆）/ policies（策略）
用户提问（文本 / 语音 / 图像证据） → 前端对话面板（Vite /ai 代理） → ai-service：RAG 检索 → 证据验证 → Prompt 组装（系统提示 + 知识证据 + 图像证据） → LLM 网关（mock / Ollama / OpenAI 兼容，可切换 Provider） → SSE 回流：thinking（思考阶段）→ token（流式正文）→ done（引用 + 可信度评分） → 高风险操作：策略引擎评估 → 人工审批 → 执行 → 审计留痕

3. 核心技术创新

3.1 可信 AI 闭环

Agent 不直接执行高风险操作：planner 拆解故障为可执行步骤，policies 策略引擎评估操作风险，高风险动作必须经人工审批；inspector 核查执行结果，全程审计留痕，体现"可信 AI"设计理念。

3.2 RAG 证据验证

混合检索（关键词 + 语义）结合证据验证机制，知识条目带版本与来源引用；回答附 citations 与 trust_score，显著降低错误版本知识干扰，回答可追溯、可核对。

3.3 AI 思考过程可视化 + SSE 流式输出

ai-service 的 chat_stream 按"图像证据解析 → 知识检索 → 证据验证 → Agent 规划 → 风险判定 → 生成回答"阶段产出 thinking 事件，前端逐步渲染思考过程并叠加流式 token 光标，将"黑盒回答"变为"透明推理"。

3.4 多模态交互

  • 语音输入：基于 Web Speech API 的渐进增强实现（Chrome/Edge 可用，不支持时自动隐藏入口）；识别文本仅填入输入框，不自动发送、不上传音频。
  • 图像证据：截屏/拍照/图片附件本地暂存，随消息仅将文件名传入 ai-service 参与模拟解析（思考链路出现"图像证据解析"阶段）；图片内容不上传。文本/日志附件走私有附件会话，仅保存证据、不参与模型分析，形成清晰的隐私边界。
  • 可视化：Three.js 3D 拓扑与 ECharts 图表呈现监控与知识分析结果。

4. 安全与可信设计

  • 权限/风险策略引擎：操作分级，高危命令默认拒绝或转人工审批。
  • 人工审批与审计留痕：关键动作全程可追溯。
  • 附件隐私设计：普通会话仅传图像文件名；私有附件会话内容不参与模型分析；提示用户遮盖密码、密钥等敏感信息。
  • 管理端安全：管理员 MFA、注册安全策略、会话管理。
